# P21: CLI y stdio de proceso

Fecha: 2026-10-28. El ejecutable instalado y python -m mealie_mcp_server usan la misma entrada. --help/--version funcionan sin configuración ni lecturas de secretos; los overrides CLI se aplican antes de cargar los secretos del transporte. Los errores de configuración se escriben en stderr, sin traceback ni valores sensibles. No se añade banner a stdout.

Se verifica un proceso real con el cliente oficial y FastMCP, tanto en auto (2026-07-28) como legacy (2025-11-25): catálogo de 78 herramientas, prompt y petición HTTP real a FakeMealie. La llamada set_recipe_image acepta exactamente 10 MiB binarios en un único mensaje base64 de unos 14 MiB, y el fake recibe los mismos bytes multipart. Se comprobó primero un fallo del test por usar image en lugar del argumento existente imageBase64; se corrigió el test, sin cambiar el contrato público.

EOF, SIGTERM y SIGINT se prueban con una conexión HTTP/1.1 persistente abierta. Los tres cierran físicamente esa conexión, emiten el diagnóstico seguro de cierre y salen con código cero. Cada línea de stdout es JSON-RPC. La primera implementación cancelaba el scope y bloqueaba al recibir SIGTERM: la lectura AsyncFile del SDK usa un hilo no cancelable. support/stdio.py incorpora un puente POSIX con buffer máximo de 64 KiB, descriptores propios y una señal de despertar; convierte las señales en EOF y restaura stdin al salir. No accede a APIs privadas MCP. El cliente HTTP protege su limpieza con un scope acotado a cinco segundos.

El runtime validado es Linux dentro del Dev Container, también cuando el cliente se ejecuta en Windows. No se afirma compatibilidad con ejecución nativa Windows. Los ejemplos Docker no asignan TTY. Los timings opcionales incluyen método y duración, nunca URL, body ni credenciales; los logs de terceros quedan en WARNING.

RED inicial: nueve fallos de CLI/stdio. Tras implementar: diez pruebas pasan, incluyendo las tres formas de cierre. Dos pruebas adicionales de FastMCP pasan; la imagen grande corregida pasa por separado. La suite completa final pasa: **814 tests en 206,64 s**, Ruff/format y mypy estricto en 79 archivos sin errores.
